# ✅ My To-Do List App

A simple and beautiful To-Do List web app to plan your day, track tasks and stay productive.

Built by Mythrri.

## 🚀 Live Demo
https://mythrri.github.io/todo-list-app/

## ✨ Features
- Add New Task in 1 Click
- Mark Task as Done ✔️ - Task gets strike-through
- Delete Task ❌
- Filter Tasks:
    - All Tasks
    - Pending Tasks
    - Done Tasks
- Live Counter - Total Tasks | Done Tasks
- Clear All Tasks in 1 Click
- Clean & Mobile Friendly UI

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (DOM Manipulation, Arrays, Filter Logic)

## 📱 How To Use
1. Type your task - Ex: Study Python
2. Click **Add ➕**
3. Click **✔️** when task is finished
4. Click **❌** to delete a task
5. Use **All / Pending / Done** buttons to filter

## 🎯 Why I Built This
I built this to learn how real apps manage data - Add, Complete, Delete and Filter. This is called CRUD operations, which is a core concept used in every real-world website and app.
